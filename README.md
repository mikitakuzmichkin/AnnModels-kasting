# ANNmodels — прототип кастингов

Кликабельный прототип по ТЗ: кабинет родителя, админка агентства и страница подборки для заказчика. Кабинет рассчитан на Telegram Mini App. Портреты вымышленные, данные живут в браузере.

Сайт агентства: [project.annmodels.by](https://project.annmodels.by/).

## Как посмотреть локально

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite.

- Приложение родителей, его и подключаете к боту: `#/app`
- Сайт администраторов: `#/admin` — логин `admin`, пароль `annmodels`
- Пример страницы для заказчика: `#/c/waikiki_autumn`

Вход родителя для показа: `+375 29 111-22-33`, код `1234`. В кабинете Алиса, Софья и Ева.

Кнопка «Сбросить демо» возвращает исходные анкеты.

## Что связано между экранами

Отклик родителя, решение администратора, плашки свежести и сообщения бота пишутся в `localStorage` этого браузера. Одобрите заявку в админке и откройте «Бот» в кабинете на том же компьютере — сообщение уже будет там.

Телефон и компьютер в прототипе не синхронизируются: сервера нет.

## Что настоящее, а что макет

Настоящее в интерфейсе:

- вход только по номеру из заявки;
- анкета, лента с фильтрами, отклик с выбором фото;
- попап, если фото, визитка или рост старше порога;
- статусы «На рассмотрении», «Приглашен», «Отказ»;
- галерея, загрузка и видеовизитка;
- конструктор кастинга и три вкладки обработки;
- замена обложки отклика кадром из галереи;
- порог плашек 90 или 180 дней;
- поиск по базе, верификация и блокировка;
- аналитика;
- публичная подборка и скачивание zip;
- календарь и кнопки напоминаний за 24 часа и за 2 часа;
- текст поста в канал и deep link `startapp`.

Макет, потому что для него нужен сервер и токен бота:

- SMS с кодом (в демо код всегда `1234`, он показан на экране входа);
- реальная отправка поста в канал;
- реальный пуш в личный чат;
- автоматический запуск напоминания по часам (кнопка показывает текст, который бот отправил бы).

## GitHub Pages

1. Создайте репозиторий и залейте эту папку в ветку `main`.
2. В репозитории: Settings → Pages → Build and deployment → Source: GitHub Actions.
3. После пуша workflow `.github/workflows/pages.yml` соберёт сайт.
4. Адрес будет вида `https://<user>.github.io/<repo>/`.

Приложение родителей: `https://<user>.github.io/<repo>/#/app`  
Сайт администраторов: `https://<user>.github.io/<repo>/#/admin`  
Подборка: `https://<user>.github.io/<repo>/#/c/waikiki_autumn`

В Mini App укажите адрес с `#/app`. Сайт администраторов в бота не кладётся: менеджеры открывают `#/admin` в браузере телефона или компьютера и входят под своим логином.

## Telegram Mini App

Mini App — это этот же HTTPS-адрес, открытый внутри Telegram. GitHub Pages такой адрес даёт сразу.

В своём Telegram откройте @BotFather:

1. `/newbot` — если бота ещё нет.
2. `/newapp` — название ANNmodels, короткое имя латиницей (`annmodels`), ссылка на Pages, картинка 640×360.
3. BotFather пришлёт `https://t.me/<бот>/<приложение>`. Её открывают родители.
4. `/setmenubutton` — та же ссылка на Pages, чтобы приложение открывалось из чата с ботом.

В админке, раздел «Плашки», впишите имя бота без `@` и короткое имя Mini App. Тогда у поста канала появится настоящая ссылка `t.me/...?startapp=waikiki_autumn`. Параметр `startapp` открывает карточку этого кастинга.

Токен бота в репозиторий класть не нужно.

Проверка с телефона: откройте ссылку `t.me`. Проверка с компьютера: тот же сайт в браузере, кабинет показан в рамке телефона.
